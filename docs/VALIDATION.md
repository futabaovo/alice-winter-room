# 1.1（v1.1.0）发布验收

2026-10-30，Windows x64 本机验证。

- 最新应用 90 项逻辑测试通过。
- 独立单文件 EXE 重新打包；验证启动与首帧交接、像素键盘、Q 版及书本小游戏。
- 上一轮 1.0.9 已完成 14 组渲染回归；1.1 保留同一批已审查美术与运行功能。
- 全部检查使用隔离测试配置，模拟键盘动作切到仅此窗口，避免用户实时敲键干扰。
- 使用应用白名单打包并检查个人路径、凭证、配置、聊天、训练数据与权重边界；构建清单与 SHA-256 随发布附上。

对话的流程验收使用本地测试接口；自由语音合成仍需要单独配置本机语音环境。本机通过不代表全部显卡、跨屏 DPI 或 Windows ARM 均已验证。白帽局部轮廓与小尺寸聊天仍可继续精修。
