# 表情变更的最低审验要求

用户要求：所有表情至少经过两轮审验。表情参数、附加眼形、眉形、瞳孔或闭眼图层发生改动后，都应覆盖整个表情目录，不能只检查刚改的一张。

第一轮：统一取景，逐张查看全强度、默认强度和低强度的原生渲染，对照参考，检查眉毛、上眼线、瞳孔、嘴型及刘海接触关系。分清眼线与眉毛，不能用重复粗线冒充层次。发现问题则修正并重做该轮。

第二轮：逐张查看原态、半眨眼、闭眼、左右视线、说话口型和从特殊表情切回的状态；同时验证真实语音的暂停、定位、结束和手动切换优先级。检查闭眼层与睁眼层是否重叠、瞳孔是否漏出遮罩、是否出现上下悬空的眼白间隙以及切换残留。

两轮均须保留截图和检查记录，并实际打开图像审看。自动检查通过只证明程序约束通过，不能替代视觉审验。当前检查入口：`--expression-audit-round=1` 和 `--expression-audit-round=2`；语音、服装和桌宠联动另由 `--verify-expressions-only` 覆盖。

眼形补正不得连带拉伸眉毛的粗细；应保留细眉与上眼线的区别。圈圈眼等特殊效果必须受原生眼白遮罩约束，在闭眼和切回时退出。
