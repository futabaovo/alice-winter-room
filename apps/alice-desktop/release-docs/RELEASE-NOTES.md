# 有珠 · 冬日小室 1.1

程序版本：1.1.0。本次将 1.0 后的 Q 版、小游戏、自然视线、像素键盘及稳定性修订汇总为正式新版。

- 立绘 / Q 版切换，三套衣装和 20 种情态；保留语音口型、举书、投喂与品茶互动。
- 3×3 书本保卫战，三档难度、分数反馈和 Robin 撞屏结算。
- Q 版独立眼球追随与轻微头部摆动，修正方向判断并减少机械摇摆。
- 独立像素键盘模式，十种快捷键动作；Ctrl+C/V 提供精细书页关键帧和连续动作衔接。
- 桌宠聊天工具默认收为一行，支持展开，改善小尺寸的人物可见性。
- 修复空资源请求异常与退出时键盘设置丢失，减少隐藏键盘窗口的重复绘制。
- 继续支持 Robin、侧边隐藏与临时企鹅装偷看、寿司、红茶、附图对话、字幕、记忆和存档。

升级前先退出旧版。已有设置和聊天沿用原用户目录；发布包不含个人配置、密钥、聊天或训练资料。自由语音合成需要另行配置本机语音环境。

## 有珠 · 冬日小室 1.0.9

- 修复本地资源服务器处理零字节文件时可能出现的未捕获异常，保留音频分段读取支持。
- 修复键盘设置修改后立即退出时，最后一次大小、衣装和位置可能未写入磁盘的问题。
- 隐藏键盘窗口后停止动画调度；待机画面未改变时跳过重复绘制和文案更新，恢复后保留眨眼及快捷键动作。
- 桌宠聊天时工具栏收为一行，点“工具”展开互动；人物按输入框实际位置布局，改善小尺寸下被控件遮挡的问题。
- 补充设置退出保存、空资源与媒体 Range、隐藏绘制计数、小尺寸人物可见性与工具展开回归。

## 1.0.8

- 像素键盘模式新增十种快捷键反馈：复制、剪切、粘贴、保存、撤销、重做、查找、全选、Enter 和 Esc。
- 三套衣装增加书页、合书、扶额、举书检视差分；保留圆团手形，按待机高度等比例注册。
- Ctrl+C/V 增加三套衣装共 18 张专用关键帧：复制翻书抽页、复制成双页再收好；粘贴取页、双手托页、落到键盘并收手，加入接触微光与渐近阴影。
- 快速连续 Ctrl+C → Ctrl+V 时依次播完复制、粘贴，延长待播有效期以匹配精细动作时长。
- 同一动作设冷却，连续操作只保留最近一次待播放反应；暂停、换装和退出模式会清空动作。
- 设置中可关闭快捷键专属动作，并逐项预览。仅此窗口模式忽略输入法组词确认、按键自动重复和设置控件输入。
- 全局服务仅发送白名单命令名称与匿名敲击脉冲，不读取剪贴板，不拦截原软件快捷键，不保存输入内容。

## 1.0.7

- 新增独立“键盘模式”：透明像素桌宠随敲击节奏交替按键，停手后回到待机并偶尔眨眼。
- 提供冬日披肩、白色冬装及企鹅服三套像素衣装；手形采用圆润整块轮廓。
- 可选全局响应或仅此窗口响应，支持暂停、鼠标点击响应、70–150%连续大小和轻动幅度调节。
- 仅传递匿名敲击脉冲，不记录或发送按键内容。退出键盘模式、休眠或锁屏时停止监听。
- 键盘模式单独保存衣装、大小与位置；返回普通桌宠或小室后恢复原有角色样式、衣装及侧边状态。

## 1.0.6

## 1.0.2

## 1.0 原有功能

将当前完整版本正式编号为 1.0（程序版本 1.0.0），现有功能全部保留。提供可独立运行的 Windows x64 版本。

- Robin 飞行启动画面，花房背景与首帧衔接。
- 20 种差分表情与分类预览；保留细眉及原生眼部遮罩修正。
- 三套衣装、连续大小、侧边隐藏和偷看、临时企鹅装探头。
- 抚摸举书、Robin 来访、六种寿司及红茶品质互动。
- 桌宠对话、读图、可选语音、头顶双语字幕、话后表情包。
- 侧栏布局、对话框透明度、记忆和存档沿用现有实现。

提供单文件 EXE 和完整便携 ZIP。用户配置、聊天、训练数据和神经模型权重不进入发布包。自由合成语音依赖另行配置的本机语音环境；内置语音可离线播放。当前版本未做代码签名。

面向 Windows 10/11 x64，要求显卡驱动支持 WebGL2；不包含 32 位或原生 ARM 构建。验证限于本机实际运行，不将其等同于全部 Windows 设备兼容认证。

升级时先退出旧程序。正式版继续使用既有 `AliceKuonjiWinter/2.4` 用户配置；源码预览的独立配置不自动迁移。
