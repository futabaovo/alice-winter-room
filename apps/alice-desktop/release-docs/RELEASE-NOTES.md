# 有珠 · 冬日小室 v3.3.0

将此前源码预览中的功能合并为可独立运行的 Windows x64 版本。

- Robin 飞行启动画面，花房背景与首帧衔接。
- 20 种差分表情与分类预览；保留细眉及原生眼部遮罩修正。
- 三套衣装、连续大小、侧边隐藏和偷看、临时企鹅装探头。
- 抚摸举书、Robin 来访、六种寿司及红茶品质互动。
- 桌宠对话、读图、可选语音、头顶双语字幕、话后表情包。
- 侧栏布局、对话框透明度、记忆和存档沿用现有实现。

提供单文件 EXE 和完整便携 ZIP。用户配置、聊天、训练数据和神经模型权重不进入发布包。自由合成语音依赖另行配置的本机语音环境；内置语音可离线播放。当前版本未做代码签名。

升级时先退出旧程序。正式版继续使用既有 `AliceKuonjiWinter/2.4` 用户配置；源码预览的独立配置不自动迁移。
