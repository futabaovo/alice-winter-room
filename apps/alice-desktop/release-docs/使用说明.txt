有珠 · 冬日小室 3.3.0 — Windows 10/11 x64

如何运行
双击 AliceKuonji-Winter-v3.3.0.exe。首次启动会将内置播放器整理到本机缓存，Robin 飞行时请稍候；后续直接复用缓存。无需安装 Node.js、Python、Live2D 编辑器或 LingChat。
也可以解压便携 ZIP 后运行 AliceKuonji.exe；请保留整个解压目录，不能单独拿走其中的 EXE。

本版功能
小室与透明桌宠；三套衣装；20 种差分表情；抚摸举书；Robin 来访；六种寿司；红茶品质与泡茶；侧边隐藏、定时偷看和临时企鹅装；连续大小、对话框透明度；头顶字幕；附图对话；记忆、存档和可选主动交流；话后表情包；Robin 启动画面。

对话与语音
右下角“对话设置”中配置自己的兼容 API，或安装并登录本机 Codex 后选择本机来源。对话与图片发送给你选择的服务。软件不包含共享 API 密钥或共享账户。
内置日语台词、童谣、Robin 短句可离线播放。
新回答的自由日语朗读需要另行配置 GPT-SoVITS 本机语音环境；本包不含 Python 环境或模型权重。在“语音”中选择你的语音环境。未配置时可关闭“语音回复”并使用文字对话。

桌宠操作
右侧工具栏点击“桌宠”。拖动身体移动，底部菜单或右键可藏至左/右侧、调节大小、换装或返回小室。收起后约 3–5 分钟偷看一次；点击侧边标签唤回。侧边位置可拖动调整。
Enter 发送，Shift+Enter 换行；附图按钮、拖图或 Ctrl+V 粘贴截图均可。语音回复开关、Robin 和字幕在桌宠界面可用。

升级与数据
先退出旧版再运行新版。正式版继续使用 %APPDATA%\AliceKuonjiWinter\2.4\，保留已有设置和聊天。本包不含你的密钥、聊天记录、记忆或存档。
此前的源码预览使用单独的预览配置目录，正式版不会自动导入该预览目录；需要在正式版重新选择相应设置。
单文件运行缓存位于 %LOCALAPPDATA%\AliceKuonjiWinter\。不要在程序运行时删除缓存。
